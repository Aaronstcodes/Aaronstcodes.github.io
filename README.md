# aaronst.me

this is my site. built it fully from scratch, no react no frameworks no nothing, just html css js. wanted to actually know what every line was doing instead of stitching together some template and calling it mine.

**live:** [aaronst.me](https://aaronst.me)

## why i made it

didn't want a portfolio that looked like everyone else's. wanted something dark, minimal, but not dead — like it's actually alive when you open it, not just a static resume with a nicer font.

## what's actually in it

- **starfield hero** — built this myself instead of grabbing a library, took way longer than it should've but worth it
- **theme switcher** — light/dark toggle
- **custom cursor** — small thing, most people won't clock it consciously but it makes the whole site feel more intentional
- **live ist clock + weather widget** — little proof the site's actually "on," not frozen
- **lanyard/spotify "now playing"** — pulls my real discord presence in real time, kind of a flex ngl
- **projects section** — updates as i build more, not a snapshot from one point in time
- **contact form** — formspree, no backend to maintain

## stack (and why)

vanilla html/css/js on purpose. i'm self taught and wanted proof i can build solid without leaning on a framework to do the thinking for me. hosted on cloudflare pages now, moved dns over from namecheap mainly so analytics + dns live in one place.

lanyard for the discord/spotify thing — small technical flex but felt worth it, real time data on a static site isn't nothing.
